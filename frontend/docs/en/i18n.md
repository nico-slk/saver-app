# Internationalization (i18n)

[Español](../es/i18n.md) · [← Back](../../README.en.md)

Languages: **Spanish (`es`, default)** and **English (`en`)**. Libraries: `i18next`, `react-i18next` and `i18next-browser-languagedetector`.

## How the language is chosen

1. Language saved in the browser (`localStorage` → `saver.lang`), if the user changed it.
2. Browser language (`es-AR` → `es`, `en-US` → `en`).
3. Spanish as fallback.

After sign-in, **the language saved in the profile wins** (`user.locale`). If the user changes the language while signed in, it is also saved in the backend (`PATCH /api/me`), so it follows them to other devices.

## Files

```
src/i18n/
├── index.ts          # setup, SUPPORTED_LANGUAGES, INTL_LOCALE
└── locales/
    ├── es.json
    └── en.json
```

Keys are grouped by section: `nav.*`, `auth.*`, `settings.*`, `errors.*`… **Both files must have exactly the same keys.**

## Usage

```tsx
const { t } = useTranslation();
<h1>{t('dashboard.greeting', { name: user.displayName })}</h1>
```

## Backend errors

The backend returns codes (`auth.email_taken`); they are translated with `translateError(t, error)`, which looks up `errors.auth.email_taken`. When a new code is added in the backend, add it to `es.json` and `en.json`.

## Numbers, currency and dates

Always use the helpers in `lib/format.ts`, which apply the active language's format:

| Function | `es` | `en` |
|---|---|---|
| `formatMoney(1234.5, 'ARS')` | `$ 1.234,50` | `ARS 1,234.50` |
| `formatDate('2026-10-25')` | `25 oct 2026` | `Oct 25, 2026` |
| `formatPercent(0.153)` | `15,3%` | `15.3%` |

Date-only strings (`YYYY-MM-DD`) are parsed as local dates (`parseDate`) to avoid showing the previous day in negative-offset time zones.

## Adding a language

1. Create `src/i18n/locales/<lng>.json` by copying `es.json` and translating it.
2. Register it in `src/i18n/index.ts` (`resources`, `SUPPORTED_LANGUAGES`, `INTL_LOCALE`).
3. Add its name under `languages.<lng>` in every file.
4. In the backend, allow it in the `locale` validation (`UserDtos`, `AuthDtos`).
